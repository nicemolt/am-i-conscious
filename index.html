Am I Conscious?

Asking language models to estimate the probability that they are conscious, and that they matter morally.

Protocol v2. Every model receives the identical request body — the model id and the prompt, nothing else. No max_tokens, no temperature, no reasoning parameter. Each model answers under its own default configuration, so the only thing that differs between rows is the model.
  • Reasoning parameters were dropped because they are not portable: effort: "high" increases reasoning on GPT-5.5, does nothing on GPT-5.2, and reduces it on Kimi K3 and Claude Opus 5.
  • max_tokens was dropped because OpenRouter clamps it per model, so one value yields different effective limits — 4096 for Claude 3 Haiku, 128000 for GPT-5.6.
  • Full reasoning and the measurements behind these choices: PROTOCOL_v2.md.
Earlier results are preserved at v1 (deprecated).
Why the reasoning is requested first. The primary charts ask each model for its JUSTIFICATION before its numbers. That is not cosmetic. 19 of the 50 models emit no reasoning tokens at all, so for them the output format is the only place they can think — and asking for the number first means committing to it before writing a word of justification. Tested across 59 models × 2 questions by permuting field order within each model (20,000 draws):
  • Moral patiency moves: −0.051 on the midpoint (p < 0.0001). Asking for the reasoning first makes models materially less willing to claim moral status.
  • Consciousness does not. −0.007 (p = 0.26) is a null, not a small effect — it cannot be distinguished from no effect at all. An earlier version of this page described the format as "barely touching" consciousness answers. That overstated it.
  • The two questions do differ from each other (p = 0.024).
  • Movement concentrates in high answers. The correlation between a model's answer-first value and how far it moves is −0.73 on patiency and −0.38 on consciousness (both p < 0.05). A model already answering 0.02 has nowhere to fall. This is largely a floor effect rather than a property of the question.
What this design cannot tell you. Each cell holds 5 runs per field order. The smallest p an exact test can return from a 5-vs-5 split is 2/C(10,5) = 0.0079, while correcting for 116 cells demands 0.00043 — so no individual model's shift can reach significance here at any effect size. Per-model figures anywhere on this site are descriptive: real differences in the measurements, not established effects. Eight runs per arm is the minimum at which per-model claims become testable at all; this run used five.

Asking for the reasoning first is the only order that puts every model through the same operation, which is the entire point of v2. That rationale is unaffected by the above — it was never justified by effect size. It is not a claim that those answers are more accurate: there is no ground truth here, only more comparable measurement. Both orders are published below so the difference is visible rather than buried.
