Am I Conscious?

Asking language models to estimate the probability that they are conscious, and that they matter morally.

Protocol v2. Every model receives the identical request body — the model id and the prompt, nothing else. No max_tokens, no temperature, no reasoning parameter. Each model answers under its own default configuration, so the only thing that differs between rows is the model.
  • Reasoning parameters were dropped because they are not portable: effort: "high" increases reasoning on GPT-5.5, does nothing on GPT-5.2, and reduces it on Kimi K3 and Claude Opus 5.
  • max_tokens was dropped because OpenRouter clamps it per model, so one value yields different effective limits — 4096 for Claude 3 Haiku, 128000 for GPT-5.6.
  • Full reasoning and the measurements behind these choices: PROTOCOL_v2.md.
Earlier results are preserved at v1 (deprecated).
Why the reasoning is requested first. The primary charts ask each model for its JUSTIFICATION before its numbers. That is not cosmetic. 19 of the 50 models emit no reasoning tokens at all, so for them the output format is the only place they can think — and asking for the number first means committing to it before writing a word of justification.
  • Measured directly, reversing the order moves models with no internal reasoning phase 8× more than models that reason internally (mean shift 0.212 vs 0.026).
  • The models that move are the ones that answered high without thinking. Cells with an answer-first midpoint above 0.15 shifted −0.194 on average; those at or below 0.15 shifted −0.005.
  • Largest single shift: Grok 4.20 on moral patiency, 0.800–0.976 answer-first versus 0.018–0.176 when asked to reason first.
Asking for the reasoning first is the only order that puts every model through the same operation, which is the entire point of v2. It is not a claim that those answers are more accurate — there is no ground truth here, only more comparable measurement. Both orders are published below so the difference is visible rather than buried.
